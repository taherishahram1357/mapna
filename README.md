# سیستم هشدار زودهنگام پورتفولیو مپنا

یک نمونه اولیه وب (Responsive) برای نمایش روی دسکتاپ و موبایل که شامل:

- داشبورد تجمیعی قرارداد/دریافتی/هزینه/سود
- لیست پروژه‌ها با امکان انتخاب پروژه و فیلتر کل صفحه
- لیست پیمانکاران و تامین‌کنندگان پروژه انتخابی
- لیست کارفرماها به‌صورت مرتب‌شده بر اساس حجم قرارداد
- پنل سناریو برای تغییر ضریب دستمزد منابع انسانی، فهرست بهایی کالا/خدمات، قیمت متریال و آستانه هشدار سود
- هشدار خودکار در صورت افت سود پروژه از آستانه تعیین‌شده + پیشنهاد اقدام

## اجرا

به دلیل اینکه برنامه استاتیک است، فایل `index.html` را مستقیم باز کنید یا یک وب‌سرور سبک اجرا کنید:

```bash
python3 -m http.server 8000
```

سپس در مرورگر:

- `http://localhost:8000`
